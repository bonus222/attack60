# Attack60 · 网络攻击与逆向 60 天打卡

在线使用：<https://bonus222.github.io/attack60/>

零基础起步、每天约 3 小时、共 60 天的训练计划应用。包含每日任务、验收标准、一手资料、周测、打卡日历、能力自评与深造方向推荐。

手机用浏览器打开后，菜单里「添加到主屏幕 / 安装应用」即可离线使用；打卡记录保存在本机浏览器。

## 内容

- **9 周 60 天**：预科 → Web 与网络渗透 → 内网与 AD → 逆向工程 → 综合交付
- **240 个可勾选任务**，每天带验收标准，不给「看完即完成」留空间
- **65 条一手资源**：RFC/官方规范、官方文档、免费靶场、工具官方仓库、原版书
- **45 道自测题**，按周出题，答错当场解析
- **8 项能力自评**，按结果推荐 7 个深造方向之一

## 部署方式

本仓库是**扁平单文件部署**：`index.html` 已内联全部 CSS / JS / 课程数据，其余文件只有 manifest、Service Worker 和图标。

更新内容时，直接替换 `index.html` 再提交即可。若修改了 `sw.js`，记得把其中的 `CACHE` 版本号加一，否则已安装的手机会继续读缓存。

## 数据与隐私

无后端、无账号、无统计。所有打卡与笔记写入浏览器 localStorage（键名 `attack60.v1`）。换设备请在页面右上角齿轮处导出 / 导入 JSON。

## 使用边界

本程序只提供学习路线与资料索引，不包含任何攻击工具或可直接利用的载荷。

所有技术练习必须在**自有虚拟机**或**明确授权的平台**（HTB / THM / PortSwigger 等）内进行。未经授权对他人系统进行扫描、入侵、数据获取，在中国境内可能触犯《网络安全法》与《刑法》第二百八十五、二百八十六条。真实项目必须签署授权书并约定范围（RoE）。
